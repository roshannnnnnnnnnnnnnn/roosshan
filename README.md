# Tetris

A classic browser-based Tetris game built with vanilla HTML, CSS, and JavaScript.

## Features

- 10 × 20 game board
- All seven standard tetrominoes
- Piece rotation and wall kicks
- Line clearing and scoring
- Increasing difficulty by level
- Next-piece preview
- Soft drop and hard drop
- Pause and restart
- Responsive layout

## How to play

Open `index.html` in a modern web browser. No dependencies or build tools are required.

### Controls

| Key | Action |
|---|---|
| ← / → | Move |
| ↓ | Soft drop |
| ↑ | Rotate |
| Space | Hard drop |
| P | Pause |
